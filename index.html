Willkommen bei FORGE

Dein Training. Dein Fortschritt. Auf deinen Geräten.

Jeder Benutzername kann nur einmal verwendet werden.

Mit Konto werden deine Pläne, Trainings, Körperdaten und Einstellungen privat in Supabase (Frankfurt) gespeichert. Freunde sehen nur deinen Anzeigenamen. Eine E-Mail-Bestätigung ist derzeit nicht nötig. Auf diesem Gerät bleibt eine Offline-Kopie.

Vorhandene Daten aus deiner bisherigen FORGE-Version kannst du nach dem Anmelden über Einstellungen → Import übernehmen.

👤 Konto & Freunde

Zwei verschiedene Datenstände

Ein anderes Gerät hat ebenfalls Änderungen gespeichert. Deine lokale Version bleibt erhalten, bis du auswählst. Vor dem Übernehmen werden beide Stände lokal gesichert.

Dein Freundescode

Teile diesen Code nur mit Personen, die dich hinzufügen dürfen.

Freunde

Kontakte sehen nur deinen Anzeigenamen. Trainings- und Körperdaten werden nicht geteilt.

Wochen-Challenges

Teile nur den Fortschritt dieser Challenge, keine Trainingsdetails.

Konto löschen

Dein Konto und alle damit gespeicherten Daten werden dauerhaft gelöscht. Diese Aktion kann nicht rückgängig gemacht werden.

👥 Plan teilen

Der Empfänger erhält eine unabhängige Kopie. Spätere Änderungen werden nicht automatisch geteilt.
